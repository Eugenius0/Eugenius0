## Featured Projects

### 🤖 [Agentic Travel Planner](https://github.com/Eugenius0/agentic-travel-planner)

An AI-powered full-stack application that researches destinations, generates personalized travel itineraries, and validates complete trip budgets using autonomous agents.

- Built an agentic workflow using **LangGraph and LangChain**, integrating **Tavily MCP** for destination research and **Groq** for LLM-powered itinerary generation.
- Implemented structured generation, budget validation, conditional routing, and automated retry mechanisms.
- Developed a responsive **Next.js, React, TypeScript, and Tailwind CSS** frontend with a **FastAPI and Pydantic** backend.
- Added automated tests using **pytest** and containerized the application with **Docker Compose**.

**Technologies:** Python, FastAPI, LangGraph, LangChain, MCP, Groq, Tavily, Next.js, React, TypeScript, Tailwind CSS, Docker

### 🧠 [AI-Driven DevOps Engineer — Master's Thesis](https://github.com/Eugenius0/multi-agent-devops-engineer)

Designed and developed an LLM-based multi-agent system to automate software engineering and DevOps workflows.

- Implemented autonomous workflows for CI/CD, infrastructure provisioning, and container management.
- Developed a multi-agent architecture incorporating reasoning, prompt engineering, and reflection.
- Integrated local LLM inference with a React/FastAPI application, Docker, and Pulumi.
- Achieved an **86.1% success rate** in the final multi-agent evaluation.

**Technologies:** Python, LLMs, Multi-Agent Systems, Ollama, FastAPI, React, Docker, Pulumi
